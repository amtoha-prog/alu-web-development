# alu-web-development

ALU Web Development project - HTML and CSS fundamentals.

## Structure

- `html_basic/` - HTML only tasks
  - `base_index.html` - base HTML skeleton
  - `index.html` - home page structure
  - `tweets.html` - page with an embedded tweet
- `css_basic/` - HTML pages styled with CSS
  - `base.css` - reset and base element styles
  - `styles.css` - layout, Flexbox and responsive rules
  - `index.html`, `tweets.html` - the pages using the stylesheets

## Requirements

- Plain HTML and CSS only
- No framework and no JavaScript library
- Flexbox based layout
- Responsive down to small screens
